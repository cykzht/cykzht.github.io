ESP8266+Arduino Development Environment Setup

发表于2022-12-14|更新于2025-08-07|英文期刊
|总字数:432|阅读时长:2分钟|浏览量:

I. Arduino IDE Installation

  1. Search for Arduino on baidu, and go to the [Arduino official website](Arduino - Home).

  2. Find and click the software option at the top of the official website.

  3. Scroll down to find the Legacy IDE (1.8.X) version. Although the latest version 2.0 has been released, the author has only tried developing 8266 using version 1.8. It is said that version 2.0 uses the VScode compilation environment, but on the author’s computer, it couldn’t even change the language. Therefore, this tutorial is based on version 1.8. Download the corresponding software version according to your system version. The author is using Windows 11, so the first one is selected. Note that you should definitely not download the Windows app version, as this is a Microsoft Store link, and compared to the installation version, it has many cutbacks, making development less smooth.

  4. This is the donation step. We simply click Just Download. If you happen to be generous and think this development software is great, you can also try donating.

  5. After downloading, it is an exe file. We simply double-click to install.

  6. The installation process is just a series of Next steps. There may be prompts to install drivers along the way; just click Install.

II. 8266 Environment Configuration

2.1 Automatic Download of 8266 Development Board Resources

  1. Click File -> Preferences in the upper right corner.

  2. Enter the following address in the Additional Board Manager URLs field:

    Click OK to save.

  3. Click Tools -> Board -> Board Manager in the top menu bar.

  4. Search for 8266 inside and download the corresponding version of the development board resource package.

    Note that the code writing method for different versions of the 8266 development board resource packages is different. Please be sure to refer to the version of the 8266 development board used by the code you downloaded.

  5. You can then see ESP8266 in Tools -> Board.

2.2 Manual Download of 8266 Development Board Resources

Some users may find that downloading the development board resources fails due to slow browsing speeds. Below is a method for manually installing the 8266 development board resource package.

  1. Download the 8266_package, which is an exe program. Simply double-click to open it, and the program will automatically install the 8266 development environment.

    Download link 1:

    [https://pan.baidu.com/s/1Q67WF1B1QGaO04g6i-U7aQ](https://g2022cyk.top/?u=https%3A%2F%2Fpan.baidu.com%2Fs%2F1Q67WF1B1QGaO04g6i-U7aQ]
    Password: 8266

    Download link 2

  2. After installation, you can directly see ESP8266 in Tools -> Board.
